# AI-Driven-Drug-Discovery-System
This project is an AI-based Drug Discovery System that analyzes chemical compounds and predicts their drug activity, toxicity level, and suitability for drug development. It also provides confidence scores and explainable insights using machine learning concepts and a Streamlit-based interface.

🎯 Features
Predicts Drug Activity (Active / Inactive)
Estimates Toxicity Level (Low / Medium / High)
Provides Drug Suitability Recommendation
Calculates Confidence Score
Explains predictions using feature-based reasoning
Displays Feature Importance Graph
Interactive Streamlit Web Interface
Random compound selection from dataset

🛠️ Tech Stack
Python
Streamlit
Pandas
Scikit-learn
Matplotlib
Joblib
Machine Learning (Random Forest)
